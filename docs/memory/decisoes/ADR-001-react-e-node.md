# ADR-001 — React no front-end e Node.js no back-end

- **Status:** aceita
- **Data:** 2026-10-01

## Contexto
Definição inicial da stack do projeto pessoal caraoke-michael.

## Decisão
- Front-end: **React**
- Back-end: **Node.js**

## Consequências
- Mesma linguagem (JavaScript/TypeScript) nas duas pontas, permitindo compartilhar tipos e validações.
- Detalhes (TS vs JS, Vite/Next, Express/Fastify/Nest, banco) ficam para ADRs seguintes.
