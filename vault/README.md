# Vault — base de conhecimento

Pode ser aberto como vault no **Obsidian** (abra esta pasta `vault/`), mas funciona com qualquer editor Markdown.
Use links `[[nome-da-nota]]` à vontade.

> ⚠️ Não guarde senhas, tokens ou chaves aqui. Segredos ficam em `.env` (ignorado pelo git).

| Pasta | Uso |
|---|---|
| `00-inbox/` | Captura rápida, sem organizar. Revisar e mover periodicamente |
| `10-ideias/` | Ideias de funcionalidades, UX, melhorias — candidatas a virar spec |
| `20-pesquisa/` | Estudos: bibliotecas, APIs de letras/músicas, concorrentes, formatos (LRC, CDG…) |
| `30-referencias/` | Links, artigos, tutoriais, inspirações visuais |
| `90-templates/` | Modelos de nota |
