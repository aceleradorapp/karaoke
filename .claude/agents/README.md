# Agentes do Claude Code

Subagentes especializados deste projeto (um arquivo `.md` por agente, com frontmatter `name`, `description`, `tools`).

Ideias para criar quando o projeto avançar:
- `revisor-frontend` — revisa componentes React (acessibilidade, hooks, performance)
- `revisor-backend` — revisa rotas/serviços Node (validação, erros, segurança)
- `escritor-specs` — transforma ideias do vault em specs no padrão do projeto
